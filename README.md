# Indicadores Educacionais – Rede Municipal de Angra dos Reis

Site estático (PWA) sem etapa de build. Painel montado a partir de fontes públicas; não é o site oficial da Prefeitura.

- Atualizar números: edite `data.js` (null = sem dado).
- Depois de mudar arquivos, aumente a versão `CACHE` em `sw.js` (ex.: `indicadores-angra-v2`) para os celulares baixarem a nova versão.
- Publicar no GitHub Pages: envie o conteúdo desta pasta para um repositório e ative Settings > Pages (branch main, pasta raiz). Funciona em `https://<usuario>.github.io/<repo>/` ou na raiz.
- Instalar no celular: abrir o endereço e usar "Adicionar à tela inicial" (Android/Chrome ou iPhone/Safari).
